# 📝 To-Do List Application

A simple command-line To-Do List application built using Python. This project helps users manage their daily tasks through a menu-driven interface.

## Features

- Add new tasks
- View all tasks
- Delete existing tasks
- Exit the application safely
- Beginner-friendly Python project

## Technologies Used

- Python 3
- Lists
- Loops
- Conditional Statements
- User Input Handling

## How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python todo_list.py
```

## Sample Output

```text
===== TO-DO LIST =====
1. Add Task
2. View Tasks
3. Delete Task
4. Exit

Enter your choice:
```
